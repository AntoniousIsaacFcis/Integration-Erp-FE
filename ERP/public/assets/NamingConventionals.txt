Angular 21 ERP Project Naming Conventions (2026)
1. Files & Folders
• Folders: kebab-case (e.g., `product-details`, `user-management`).
• Files: kebab-case with type suffix (e.g., `auth.service.ts`, `login.component.ts`, `permission.guard.ts`).
-------
2. Components
• Class Name: PascalCase with 'Component' suffix (e.g., `ProductListComponent`).
• Selector: kebab-case with 'app-' prefix (e.g., `app-product-list`).
-------
3. Services & Models
• Services: PascalCase with 'Service' suffix (e.g., `AuthService`).
• Interfaces: PascalCase starting with 'I' (e.g., `IUser`, `IOrder`).
• Types/Enums: PascalCase (e.g., `UserRole`).
-------
4. Signals & Variables
• Signals: camelCase (e.g., `currentUser = signal(...)`).
• Computed: camelCase (e.g., `isLoggedIn = computed(...)`).
• Methods: camelCase (e.g., `onSubmit()`).
-------
5. Interceptors & Guards
Interceptors: camelCase (e.g., errorLogger).
Guards: camelCase (e.g., permissionGuard).
Resolvers: camelCase (e.g., productDataResolver).
-------
6. Directives & Pipes
Directives:  PascalCase + Directive suffix  (e.g., NumberOnlyDirective).
Pipes: PascalCase + Pipe suffix (e.g., SaudiRiyalPipe).

│   │   │   ├── components/      # Generic UI (Button, Input, Table)

│   │   │   ├── directives/      # Permissions, ClickOutside
│   │   │   └── pipes/           # Currency, DateFormatter

│   │   │   ├── inventory/
│   │   │   └── accounting/

│   ├── theme/                   # (The Soul) - Global Design System
│   │   ├── _variables.scss      # CSS Variables (Single Source of Truth)
│   │   ├── _typography.scss     # Fonts, Sizes, Line Heights
│   │   └── _components.scss     # Complex UI Patterns (using @apply)

├── tailwind.config.js           # (The Engine) - Design Tokens Mapping
├── postcss.config.js            # CSS Processing
├── tsconfig.json                # Path Aliases (@core, @shared)
└── package.json                 # Dependencies
